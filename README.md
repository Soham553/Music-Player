# 🎵 Music Player

## Overview

Music Player is a web-based application that allows users to play, pause, skip, and manage audio tracks through a simple and interactive interface.

The project focuses on creating a smooth audio playback experience with essential music controls and a clean user interface.

---

## Features

* Play and pause songs
* Next and previous track controls
* Progress bar with seek functionality
* Display song title and artist
* Album cover display
* Playlist support
* Real-time duration tracking
* Responsive design for multiple devices

---

## Tech Stack

### Frontend

* HTML
* CSS
* JavaScript

### Audio Handling

* HTML5 Audio API

---

## Project Objective

The main objective of this project is to understand how browser-based audio systems work and how to build an interactive media application using core web technologies.

---

## How It Works

1. Load songs into the playlist
2. Select or auto-play a song
3. Control playback using player controls
4. Track song progress in real time
5. Switch between songs seamlessly

## Core Functionalities

### Play Music

Start audio playback instantly.

### Pause Music

Pause the currently playing track.

### Next / Previous

Navigate through playlist tracks.

### Seek Functionality

Move to any part of the song.

Track progress dynamically.
